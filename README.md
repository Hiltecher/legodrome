# Legodrome
Mano Manikandan and Ivan Meister's coursework submission for F20GA.  

## The idea

With a shared interest in lego and Formula 1 we decided to work on a dynamic, close-up scene of a Lego Formula 1 Grand Prix, dubbed the "LEGODROME". The theme combines the high-octane world of Formula 1 with the distinct, modular aesthetic of Lego toy bricks. The technical focus was on efficient modeling and the implementation of materials and simple but efficient geometry. Key techniques included using the Array Modifier to efficiently stack components for the grandstand and sign structure, Beveling to ensure clean, low-poly geometry on the track base, and advanced UV Mapping techniques to resolve texture stretching issues on the diorama's baseplate and frame elements.
